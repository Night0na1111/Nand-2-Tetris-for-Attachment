軟體:	
	這部分牽扯到滿多平時電機不會學到的概念，可能要要求讀點書。
	要求大家寫Compiler會太強人所難，因為很少人會對程式語言有那麼高的熟悉\實作能力。
	但是一些概念要到:

	編譯流程: 機械語言 <- 組合語言 <- VM語言 <- Jack語言

	CH6(組譯器):  組合語言中的Symbol, A,D寄存器,簡單的指令翻譯

	CH7(VM I):  Stack operations, Heap, Frame, 一些特殊的記憶體位置 EX RAM[0~16]
	CH8(VM II):  Function Call在Stack上的生命週期, BootStrapping, 	

	CH9(高階語言):
		這裡會有點問題，大家都沒有學過"物件導向"，只有上過佳盈老師的C課程(C++ 才是物件導向, 不是C)。
		所以...可能要花點時間教物件導向的概念。 Class, method, function.  Static, field, variable 這些語法的用途。
		Jack語言的文法(let, 沒有 ==, 沒有指標)。

	CH10(編譯器 I):
	CH11(編譯器 II): 這兩個章節對我來說完全是黑盒子，對Coding有絕對把握的人再挑戰。
			 不然這個搞整個學期都沒完沒了。  但是因為N2T沒有附贈編譯器，就是要有人寫\提供。

	CH12(JACK OS):
			這個章節的Code都可以丟到網頁編譯器上進行驗證，甚至會進行模擬(但是不會給你VM code)。
			除了比較短的組件，剩下的基本上都是三堂課講解一個的大小。
			每個組件都有他自己的公式, 目的, 技巧, 這些請"務必" 在講的時候講清處。

			甚至還會牽扯到Jack語言的"特性"。				
			特性:Array 能夠當作指標用, 
			     Array數據超過宣告大小會直接造成記憶體複寫。
			     預先生成 BitMask 省週期的技巧。
			     編譯器不接受32768(100000000000000)這個值(必須在runtime用加法生成)。
			     Function Call 很慢(因為要生成新的Frame 執行 然後再把工作交還給Caller)。
			     不要碰特殊字元(Compiler會出事)，
			     就算retrun() 永遠不會被碰到，還是要在function/method的尾巴加上return(); 不然編譯器不懂得要幫frame進行收尾。
			     沒有 "!", 所有需要用到! 的判斷式都要改寫成在判斷後進行反轉 ~()。
